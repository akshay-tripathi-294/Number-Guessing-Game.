# Number Guessing Game 
A simple Number guessing Game made using Pyhton.

## Features
- Random number generation
- 5 chances to guess
- Too High / Too Low hints
- Last chance alert 
- Game Over message
- Secret number reveal

## Technologies Used 
-Pyhton
-Random Module

## how to Run
Python number_guessing_game.py
